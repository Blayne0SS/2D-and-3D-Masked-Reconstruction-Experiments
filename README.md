This workspace will contain the low, medium and high computational autoencoder models.

The low computation models utilised https://www.kaggle.com/datasets/avnishnish/mnist-original/data and serverd as
providing a foundational under standing of autoencoders, (what they are,how to run them, low level mask reconstruction 
and comparasion ) 

The medium computation models will utilised https://www.kaggle.com/datasets/ashery/chexpert/data. 
It will filtered out the data into healthy and unhealthy images. The first models will be autoencoders created for 
the chexpert dataset that have been published in scientific reports. Theses models will be a diffusion, masked, variational and UNET. The second types of models will be
alterations of the first in an attempt to improve reconstruction. Reconstruction will focus on rebuilding a 'healthy' version
of a unhealthy persons chest x-ray and perfomaning a comparsion to determine model effectiveness. 

Theses models will require the use of QUT HPC.
